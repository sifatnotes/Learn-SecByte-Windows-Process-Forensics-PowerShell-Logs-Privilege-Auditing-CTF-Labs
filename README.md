## Categories

- **Process forensics:** Process execution, process relationships, and service activity.
- **Shell investigation:** Examining shell-related activity and artifacts.
- **PowerShell analysis:** Reviewing logs and investigating command activity.
- **Defender monitoring:** Investigating security-product logs and related events.
- **Privilege auditing:** Reviewing permissions, privileges, and group membership.
- **Account security:** Investigating unusual, unexpected, or potentially abandoned accounts.

## Recommended Learning Path

1. Start with **Windows Process Sleuth** and **Windows Service Sleuth**.
2. Continue with **Process Chain Secrets** and **Tree of Clues**.
3. Explore **Shell Sleuth** to investigate shell-related activity.
4. Practice log analysis with **PowerShell Log Hunt** and **PowerShell Log Trails**.
5. Review **Defender Log Hunt** for security monitoring practice.
6. Finish with **Privilege Ledger Hunt**, **Group Trail Detective**, **Ghosted Accounts**, and **Ghost Accounts**.

Use the prerequisites and exercise guidance on each original page to adjust the learning order.

## How to Use the Labs

1. Select a lab and open its direct Learn SecByte link.
2. Review the learning objectives and permitted environment.
3. Examine the available evidence and follow the exercise instructions.
4. Document findings, relevant artifacts, and reasoning.
5. Revisit unfamiliar Windows security concepts and practice again.

Treat suspicious activity as a lead to investigate rather than proof of compromise. Do not disclose credentials, sensitive data, or restricted challenge solutions.
